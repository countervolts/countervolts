# things ive coded

## music

**[Volta](https://github.com/countervolts/Volta)** · native iOS music player for your own server (Subsonic/Navidrome, Jellyfin, Emby, Plex)

**[Volta Player](https://github.com/countervolts/Volta-Player)** · the web version, self-hostable, for Navidrome and local music · [try it](https://player.voltamusic.xyz)

**[Volta Desktop](https://github.com/countervolts/Volta-Desktop)** · native desktop port for Windows, macOS and Linux, written in Rust

## upscaling

**[d4r](https://github.com/countervolts/d4r)** · first ever way to run official NVIDIA DLSS (SR, RR, MFG) on AMD RDNA2/3/4 · Windows and Linux

**[m4r](https://github.com/countervolts/m4r)** · first ever Apple MetalFX upscaling, frame generation and denoiser on AMD RDNA2/3/4 · Windows and Linux

**[x4r](https://github.com/countervolts/x4r)** · first ever Intel XeSS (SR) (XMX) translated to run on AMD RDNA3/4 · Windoes and Linux

**[anf4r](https://github.com/countervolts/anf4r)** · probably first Qualcomm Adreno Neural Fusion (SR + frame generation) running on AMD RDNA2/3/4 · Windows and Linux
